SED (Stream Editor) – Text Replace / Modify
Basic syntax
sed 's/old/new/' file

Replace first match
sed 's/error/ERROR/' app.log

Replace all
sed 's/error/ERROR/g' app.log

In-place edit
sed -i 's/8080/9090/g' config.yaml

Delete lines
sed '/ERROR/d' app.log


📌 Use sed when:
➡ Replace, delete, edit text line by line



AWK – Column & Pattern Processing
Print specific column
awk '{print $1}' file

Print multiple columns
awk '{print $1, $3}' file

With condition
awk '$3 > 500 {print $1, $3}' data.txt

Field separator
awk -F ":" '{print $1}' /etc/passwd


📌 Use awk when:
➡ Structured data (columns, logs, metrics)


🔧 SORT – Sorting Text
Normal sort
sort file

Numeric sort
sort -n numbers.txt

Reverse
sort -r file

Unique
sort file | uniq

Sort by column
sort -k2 file


📌 Use sort when:
➡ Ordering logs, reports, numbers

Linux disk management
1. blkid
 - blkid -i /dev/sda1
 - blkid -p /dev/sda1

2. lsblk -a or -l
    df -h
    du -h

| Column      | Meaning                         |
| ----------- | ------------------------------- |
| NAME        | Device name                     |
| MAJ:MIN     | Kernel device numbers           |
| RM          | Removable (1 = yes, 0 = no)     |
| SIZE        | Size of device                  |
| RO          | Read-only (1 = yes)             |
| TYPE        | disk / part / loop              |
| MOUNTPOINTS | Where it is mounted in Linux FS |
